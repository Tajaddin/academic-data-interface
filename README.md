# Academic Data System

A React + TypeScript single-page application for managing academic data across multiple user roles (student, staff, advisor, instructor). Built for COP 4020.

## Tech Stack

- React 18, TypeScript, Vite
- React Router v6
- Bootstrap 5 + React Bootstrap

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
```

## Roles

The app supports four role-based views authenticated via session storage:
- **Student** — course registration and grade viewing
- **Staff** — administrative management
- **Advisor** — student advising
- **Instructor** — course and grade management
